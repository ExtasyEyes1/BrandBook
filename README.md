# TOURFORM

Сервис для подбора визуального стиля музыкального тура: данные артиста, палитра, шрифтовая пара и кегль сразу применяются к афише, футболке и худи.

Карточка соцсетей и афиша показывают общий слоган и выбранную композицию. В итоговом брендбуке собраны бриф и настройки; кнопка «Печать / PDF» открывает диалог браузера, где можно выбрать сохранение в PDF. Черновик хранится только в текущем браузере.

| Папка | Участник | Часть |
|---|---|---|
| `extzy/` | extzy (лид) | `index.html` — разметка |
| `itsarisplaz/` | itsarisplaz | `styles.css`, `fonts/` — оформление |
| `verakaw/` | verakaw | `app.js` — поведение и сохранение |

Подробности в README каждой папки.

## Запуск
Из этой папки: `python -m http.server 8000`, затем открыть `http://localhost:8000/extzy/index.html`. Через `file://` модуль `app.js` не загрузится.

## Пути
`extzy/index.html` подключает `../itsarisplaz/styles.css` и `../verakaw/app.js`. Если в репозитории все файлы лежат в корне, замените эти пути на `styles.css` и `app.js`, а папку `fonts/` положите рядом со `styles.css`.

# Вклад itsarisplaz — визуальная часть

## Этап 3: композиция афиши, фоны, две палитры

| Что | Как |
|---|---|
| Центральная композиция | Афиша фиксированного формата 4:5 (сетка: подзаголовок, центр, города, хэштег). Имя артиста — самый крупный текст (`11cqi` × кегль), название тура в 2 раза мельче, города — маленькие заглавные буквы внизу. Все размеры в `cqi`, поэтому пропорции одинаковы на телефоне и на широком экране |
| Фоны | 5 SVG в `backgrounds/`, по одному на палитру: лаймовые звуковые волны, оранжевые солнечные лучи, красные мазки и точечный растр, фиолетовый эквалайзер, кобальтовая сетка-чертёж. Подключаются через `.poster[data-palette=…] .poster-bg` |
| Читаемость | `.poster-shade`: радиальная подложка цвета афиши за центром и градиент снизу за городами (`color-mix`) |
| Новые палитры | **Ultraviolet** (фиолетовая ночь: #1c1433 / #b48cff) и **Cream Cobalt** (светлая афиша: #efe6d2 / #2747d9, кнопка с белым текстом). Для каждой заданы цвета афиши, мерча и свои постоянные образцы |
| Города | Разделитель «·» только между городами. В начале перенесённой строки его скрывает класс `.is-row-start` из `app.js`. Город в редакторе — «таблетка» с кнопкой ×. Стили `.secondary-button` и `.city-*` |

Права на фоны: все 5 SVG нарисованы с нуля для проекта (простые фигуры), сторонних изображений нет.

## Этап 2: мерч, шрифты, кегль, исправление палитр

| Что | Как |
|---|---|
| Футболка и худи | Цвет ткани — `fill` SVG через переменные `--tee` и `--hoodie`. Принт масштабируется вместе с макетом (container query, единицы `cqi`) |
| Цвета мерча по палитрам | Для каждой палитры заданы `--tee/-ink/-accent` и `--hoodie/-ink/-accent`. Одна вещь всегда тёмная, другая цвета акцента (в Red Ink — светлая футболка и тёмное худи), текст контрастный |
| Шрифтовые пары | `:root[data-font-pair=…]` задаёт `--font-display` (заголовок и имя артиста) и `--font-text` (дополнительный текст). `@font-face` берёт `local()`, затем файл из `fonts/` |
| Кегль | Переменная `--type-scale` (0.8–1.3) умножает размер заголовка афиши, имени и названия тура на мерче. Длинные слова переносятся (`overflow-wrap`), класс `.is-overflowing` подсвечивает переполненный макет |
| **Баг образцов палитр** | Второй кружок первой палитры брал `var(--accent)`, который меняется при выборе палитры. Теперь у каждого образца свои фиксированные цвета |
| Состояния | Выбранная палитра и пара: рамка, фон, у палитры галочка ✓. Фокус — рамка цвета текста (лаймовая на светлом фоне почти не видна) |
| Адаптивность | Одна колонка до 980 px, мерч в одну колонку до 520 px, учитывается `prefers-reduced-motion` |

# Вклад verakaw — интерактивность

## Этап 4: карточка и печать

`app.js` связывает карточку и брендбук с общими настройками, сохраняет слоган, бриф и композицию в черновик версии 4 и открывает диалог печати. Старые черновики получают значения по умолчанию. Проверка: изменить текст и композицию, обновить страницу и нажать «Печать / PDF».

## Этап 3: города, фоны, сохранение

| Что | Как |
|---|---|
| Города | `state.cities`, `addCity()` / `removeCity()`. Пробелы убираются, название обрезается до 30 символов. Не больше 12 городов, повторы (без учёта регистра) не добавляются, на пустое поле выводится понятное сообщение. Enter в поле добавляет город, а не отправляет форму |
| Предпросмотр | `renderPosterCities()` заполняет `#poster-cities`. Пустой список скрывает `#poster-route` целиком: без пустой строки и разделителей |
| Фокус | После удаления фокус переходит на следующую кнопку удаления, а если городов не осталось — в поле ввода |
| Помещается ли | `cityLines()` считает строки списка. Больше 3 строк — подсказка «удалите часть городов / сократите / уменьшите кегль». Отдельно проверяется обрезка центрального блока афиши |
| Фоны и палитры | `PALETTES` — 5 значений. Фон меняется через `data-palette` на афише, его ставит `applyPalette()` |
| Сохранение | `version: 3`, поле `cities`. `normaliseCities()` чистит список из черновика. Черновики версий 1 и 2 открываются с пустым списком городов |

Проверка: добавить 3 города, перезагрузить страницу — список на месте. Добавить 12 длинных городов — появится подсказка. Удалить все — блок городов на афише исчезнет.

## Этап 2: общие настройки, шрифты, кегль, сохранение

| Что | Как |
|---|---|
| Общие настройки | Один объект `state`: `artist`, `tour`, `palette`, `fontPair`, `textSize`. `renderAll()` применяет его к афише, футболке и худи сразу |
| Текст на всех макетах | Обновляются все элементы `[data-preview="artist"]` и `[data-preview="tour"]` (раньше — только первый) |
| Шрифтовая пара | `data-font-pair` на `<html>` + радиокнопки. `checkFontPairs()` проверяет через `document.fonts.load`, загрузился ли шрифт с кириллицей, и выводит предупреждение у пары. Старые ID пар из черновика (`bups-mulish`, `ceremonious-mulish`, `minsans-snell`) переводятся на замены через `LEGACY_FONT_PAIRS` |
| Кегль | Ползунок 80–130 %, шаг 5. Значение в CSS-переменной `--type-scale`. `checkFit()` после каждого изменения ищет переполненные макеты и подсказывает уменьшить кегль или сократить текст |
| Сохранение | Ключ тот же — `tourform-draft`, добавлено поле `version: 2`. Черновик сохраняется при каждом изменении и кнопкой |
| Совместимость | `normaliseDraft()` принимает старый черновик `{artist, tour, palette}` и подставляет значения по умолчанию для отсутствующих или неверных полей |
| Хранилище недоступно | Показывается `#storage-message`, введённые данные остаются на странице. Сломанный JSON в черновике считается пустым черновиком, а не ошибкой хранилища |
