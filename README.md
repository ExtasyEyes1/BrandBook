# Вклад extzy (лид)

Первый каркас TOURFORM: семантическая разметка главной страницы, форма данных тура, блок выбора палитры и область предпросмотра афиши.

Точки интеграции:

- `../itsarisplaz/styles.css` — оформление интерфейса;
- `../verakaw/app.js` — синхронизация формы и предпросмотра.

# Вклад itsarisplaz

Визуальная система каркаса: типографика, палитры, состояния фокуса, адаптивная сетка редактора и стили предпросмотра афиши.

Файл `styles.css` подключается из `extzy/index.html` и использует `data-palette` на корневом элементе для переключения цветовых направлений.
# Вклад verakaw

Минимальный слой поведения редактора: синхронизация полей с афишей, переключение палитр, сохранение черновика в `localStorage` и доступные состояния кнопок.

Скрипт подключается как ES-модуль в `extzy/index.html`.
